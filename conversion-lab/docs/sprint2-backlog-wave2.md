## Детальные тикеты спринта 2

### [QC-W2-A4] Welcome Starter Kit (+25% QCC на 72 часа)
- **Цель:** Рост конверсии новичка в первую оплату в первые 3 дня жизни аккаунта.
- **Описание:**
  1. В Личном кабинете на `/profile/plans` для пользователей с `created_at < 72h` и 0 покупок выводить приветственную модалку Starter Kit.
  2. Текст оффера: `Starter Kit для новых авторов: +25% QCC к первой покупке (1 250 вместо 1 000 за $20)`.
  3. Честный обратный отсчет дедлайна с сервера: `До сгорания бонуса: 71:59:14`.
  4. Кнопка `Забрать +25% QCC` переводит в Stripe Checkout с примененным серверным промокодом `STARTER25`.
  5. По истечении 72 часов с момента регистрации оффер блокируется на бэкенде и модалка больше не отображается.
- **Критерии приемки (AC):**
  - Given: Новый пользователь заходит на страницу тарифов в окне 72 часов с момента регистрации.
  - When: Страница загружается.
  - Then: Отображается модалка с тикающим таймером. Клик по кнопке открывает чекаут с расчетом 1 250 QCC за $20.

### [QC-W2-A8] Персональный таймер-оффер на 5 минут (−20% на 1-й месяц)
- **Цель:** Спасение сомневающихся пользователей, зависших на странице тарифов без покупки.
- **Описание:**
  1. Триггер срабатывания: пользователь без покупок проводит на `/profile/plans` > 45 секунд без перехода к чекауту (и Starter Kit уже истек).
  2. В правом нижнем углу всплывает карточка с таймером 05:00: `Персональная скидка −20% на первый месяц: $16 вместо $20 · Только сейчас`.
  3. Одновременно над навигацией появляется липкая оранжевая полоса с синхронным обратным отсчетом.
  4. Все цены тарифных карточек на странице временно пересчитываются (зачеркнуто $20, крупно $16).
  5. Правило честности `meta/rules/temporary-offers.md`: выдается строго 1 раз в 30 дней на аккаунт. Таймер хранится на сервере (`expires_at`), перезагрузка страницы не сбрасывает время.
- **Критерии приемки (AC):**
  - Given: Пользователь находится на странице тарифов 45 секунд.
  - When: Срабатывает триггер `pricing_page_hesitation`.
  - Then: Появляется карточка с таймером 05:00. При перезагрузке страницы таймер продолжает обратный отсчет с серверной отметки. По истечении 5 минут цены возвращаются к базовым ($20/мес).

### [QC-W2-A9] Exit-Intent оверлей спасения сессии (+300 бонусных QCC)
- **Цель:** Перехват пользователя в момент попытки закрыть страницу тарифов.
- **Описание:**
  1. Триггер: курсор пользователя выходит за пределы верхней границы документа (`mouseleave` к вкладкам браузера).
  2. Показывается модальный оверлей: `Не уходите с пустыми руками! Заберите +300 бонусных QCC к любому выбранному плану`.
  3. Кнопка: `Применить бонус +300 QCC` (применяет код `BONUS300` к сессии и подсвечивает карточку плана).
  4. Кнопка закрытия `×` закрывает оверлей без навязчивых повторов (не чаще 1 раза в 30 дней).
- **Критерии приемки (AC):**
  - Given: Пользователь двигает курсор к закрытию вкладки.
  - When: Срабатывает событие `mouseleave` по верхнему краю окна.
  - Then: Мгновенно появляется модальное окно спасения сессии. Клик по CTA добавляет +300 QCC к выбранному плану.

### [QC-W2-B3] Интерактивная карточка ошибки 402 с умной паузой задачи в чате IDE
- **Цель:** Превращение тупикового обрыва генерации из-за нехватки баланса в прямую докупку пака.
- **Описание:**
  1. При получении ошибки `HTTP 402 Payment Required` десктопный клиент скрывает системное сообщение и рендерит интерактивную брендовую карточку прямо в ленте чата.
  2. В карточке отображается точный расчет дефицита: `Требуется для задачи: 160 QCC | На балансе: 40 QCC | Не хватает: 120 QCC`.
  3. Рекомендация пака: `Пак 500 QCC ($10) покроет задачу и оставит запас на ~30 запросов`.
  4. Кнопка `💎 Купить 500 QCC ($10)` открывает встроенный Stripe Checkout в 1 клик.
  5. **Умная пауза:** Незавершенная задача пользователя переводится в состояние `paused_waiting_credits`. После подтверждения зачисления кредитов задача автоматически возобновляется без повторного ввода промпта!
- **Критерии приемки (AC):**
  - Given: Баланс пользователя 20 QCC, он запускает генерацию Claude Opus (~40 QCC).
  - When: API возвращает статус 402.
  - Then: В чате рендерится карточка с расчетом нехватки 20 QCC и кнопкой быстрой докупки пака. Задача встает на паузу и стартует сразу после оплаты.

### [QC-W2-B7] Пилюля активного промокода с живым таймером в статус-баре IDE
- **Цель:** Постоянное визуальное присутствие дедлайна активного персонального оффера внутри десктопного редактора.
- **Описание:**
  1. При наличии у пользователя активного серверного оффера с `expires_at > now()` в статус-баре IDE (рядом с аватаром) отображается пилюля: `⚡ −20% скидка · 04:48` с пульсирующей точкой.
  2. Таймер тикает каждую секунду в реальном времени.
  3. Клик по пилюле открывает системный браузер по ссылке `/profile/plans` с бесшовной авторизацией и предзаполненным промокодом.
  4. После истечения дедлайна пилюля плавно исчезает из статус-бара.
- **Критерии приемки (AC):**
  - Given: Пользователю выдан активный временный оффер (Starter Kit или 5-минутная скидка).
  - When: Пользователь работает в IDE.
  - Then: В правом нижнем углу видна пилюля с тикающим таймером. Клик переводит на страницу оплаты со скидкой.

### [QC-W2-B9] Win-Back баннер возврата после 14+ дней неактивности
- **Цель:** Реактивация заснувших пользователей и возврат их в платежный цикл.
- **Описание:**
  1. Триггер: первый запуск IDE пользователем после паузы >= 14 дней с момента последней активности (`last_active_at`).
  2. В `SubscriptionBannerWidget` над чатом выводится баннер: `С возвращением! Дарим +200 бонусных QCC к любому пополнению на этой неделе · Промокод BACK200`.
  3. Кнопка CTA: `Активировать бонус` → открывает модалку пополнения баланса с предвведенным промокодом.
  4. Кнопка `Skip` скрывает баннер на 7 дней.
- **Критерии приемки (AC):**
  - Given: Пользователь не заходил в Quadcode AI более 14 календарных дней.
  - When: Запускает десктопное приложение.
  - Then: Над чатом появляется баннер с предложением реактивационного бонуса +200 QCC.
